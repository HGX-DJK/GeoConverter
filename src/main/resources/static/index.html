使用帮助

CSV/Excel 转 SHP

  1. 上传 CSV 或 Excel 文件（文件需包含几何坐标列）
  2. 选择与原文件一致的编码（中文文件常用 GBK 或 UTF-8）
  3. 指定包含几何数据的列名（如 geometry、geom、wkt），或留空自动检测
  4. 选择几何类型（点/线/面），或留空自动检测
  5. 点击转换，下载生成的 Shapefile ZIP 包

几何列格式示例：

  • 点：POINT (116.4 39.6)
  • 线：LINESTRING (116.4 39.6, 116.5 39.7)
  • 面：POLYGON ((116.4 39.6, 116.5 39.6, 116.5 39.7, 116.4 39.7, 116.4 39.6))

SHP 转 CSV/Excel

  1. 上传完整的 Shapefile 文件（.shp, .shx, .dbf, .prj, .cpg）
  2. 支持多选文件同时上传，或上传包含所有文件的 ZIP 包
  3. 选择输出格式（CSV 或 Excel）
  4. 选择输出编码
  5. 点击转换，下载转换后的文件

常见问题

转换后中文乱码？
请确保选择的编码与原始文件编码一致。UTF-8 编码的文件应选择 UTF-8，GBK 编码的文件应选择 GBK。
只看到 the_geom 列？
Shapefile 由多个文件组成（.shp/.shx/.dbf/.prj/.cpg）。请确保同时上传所有相关文件，或打包成 ZIP 上传。
几何列自动检测失败？
请手动指定几何列名，系统会查找包含 WKT 格式几何数据的列。
